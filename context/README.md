# context/

Memory files — what an assistant needs to know cold.

## Files

* **MUSE.md** — who I am: identity, background, gear, how I like to work, home comfort rules. Portable across projects.
* **site-profile.md** — the house: solar array, Powerwall, interconnection, rates, automations, logging. Project-specific.

## Rules

* **Slow truths only.** Nothing with a date on it — no battery percentages, no daily numbers, no account numbers. Dated state lives in the logger and repo docs.
* **No secrets.** Tokens, account numbers, and credentials never go in these files.
* **One home per fact.** If it lives here, it doesn't also live in the other file.

## Loading into memory

Tell the assistant "load this into your memory" (or equivalent) and it distills the durable facts into its own memory. The file stays the exact reference.
